# Installation

## Requirements

- Python 3.11 or later
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

## Install from PyPI

```bash
pip install docunderstand
```

Or with uv:

```bash
uv add docunderstand
```

## Install from source

```bash
git clone https://github.com/DecisionNerd/docunderstand
cd docunderstand
uv sync --all-extras
```
